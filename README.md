# 🇬🇧 English Step by Step (A1 → B1)

Сайт для изучения английского языка — от уровня начинающего (A1) до среднего (B1).
Построен на чистом HTML, CSS и JavaScript без использования сторонних фреймворков и библиотек.

## 🚀 Возможности

- **30 полноценных уроков**:
  - **A1 Beginner** (1–10): основы грамматики, базовый словарный запас, Present Simple, to be, can.
  - **A2 Elementary** (11–20): Past Simple, правильные/неправильные глаголы, степени сравнения, going to, will, модальные глаголы.
  - **B1 Intermediate** (21–30): Present Perfect, Past Continuous, Conditionals (1 и 2), Passive Voice, Reported Speech, Relative Clauses, Used to.
- **Интерактивные упражнения (5 типов)**:
  - Выбор варианта (Quiz)
  - Вставка пропущенного слова (Fill in the blank)
  - Сопоставление пар (Match)
  - Правда / Ложь (True/False)
  - Порядок слов в предложении (Word order)
- **📚 Словари по уровням**:
  - Более 800 наиболее употребимых слов с транскрипцией (IPA) и переводом
  - Удобная разбивка по категориям
  - Встроенный быстрый поиск по английским и русским словам
- **Сохранение прогресса**: результаты уроков и баллы сохраняются в `localStorage` браузера
- **Тёмная и светлая тема**: переключение кнопкой 🌙/☀️
- **Адаптивный дизайн**: одинаково удобно пользоваться на компьютере, планшете и смартфоне

## 📂 Структура проекта

```text
├── index.html          # Главная страница SPA
├── css/
│   └── style.css       # Все стили (темы, анимации, адаптив)
└── js/
    ├── app.js          # Роутер, движок квизов, логика UI
    ├── lessons-a1.js   # Уроки уровня A1
    ├── lessons-a2.js   # Уроки уровня A2
    ├── lessons-b1.js   # Уроки уровня B1
    └── vocabulary.js   # Базовый словарь по уровням и категориям
```

## 🛠 Запуск

Просто откройте `index.html` в любом современном браузере. Веб-сервер не требуется!
